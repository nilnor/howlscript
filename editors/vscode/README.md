# Howlscript for VS Code

Support for [Howlscript](https://howlscript.io/), a language that compiles to Lua for
LuaJIT 2.1 and Lua 5.2 to 5.5, in `.howl` files:

- **Highlighting,** also of `howl` code blocks in Markdown.
- **Indentation:** a new line is indented after a block's header, a function arrow
  or an opening bracket, and `else`, `elseif` and closing brackets line up as you
  type them.
- **Folding** by indentation.
- **Comments:** toggling line comments, with `--`.
- **Brackets and quotes** close as you type them.

The language is described on [howlscript.io](https://howlscript.io/), which has a
manual and the reference.
